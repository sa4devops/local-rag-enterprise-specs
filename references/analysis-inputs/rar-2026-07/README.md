# AQL — Complete Architectural Review Request Package

هذه الحزمة تحتوي سبع وثائق مستقلة، كل وثيقة مصممة لتُعطى إلى **Claude Architecture** منفردة قبل أي تعديل على المستودع.

## طريقة الاستخدام

1. أعطِ Claude ملفاً واحداً فقط في كل مرة.
2. أرفق روابط المستودعات الحاكمة والتنفيذية الحالية.
3. اطلب منه فحص `HEAD` الفعلي وعدم الاعتماد على الذاكرة أو التقرير وحده.
4. لا تسمح له بتعديل أي مستودع في مرحلة الدراسة.
5. راجع الحكم المعماري، والبدائل، وخطة الملفات، وقرارات المالك.
6. بعد الاعتماد فقط، استخدم Prompt Claude Code الذي سيكتبه Claude في الملحق.
7. نفّذ كل RAR في PR مستقل ما لم يثبت Claude أن دمج بعضها هو الخيار الصحيح.

## قواعد ثابتة للحزمة

- الوثائق لا تفرض أسماء ملفات أو تقنيات.
- المستودع الحاكم يتقدم عليها عند التعارض.
- Claude Architecture يدرس ويقترح ولا ينفذ.
- Claude Code ينفذ فقط بعد اعتماد المالك.
- لا تُعتبر أي فجوة مثبتة قبل فحص المستودع الفعلي.
- لا يدخل الجرد التاريخي الكبير للميزات في هذه الحزمة كقائمة تفصيلية؛ يعالج لاحقاً في Reconciliation مستقل.
